# Gutenkern — алгоритм генерації пар

Спільне джерело правди для Swift- і C#-реалізацій. Поведінку фіксують тести з `fixtures.json`.

## Парсер

Вхід — один рядок (або кілька, з переносами). На виході — список токенів:

- **character** — один графемний кластер (звичайна літера, включно з кирилицею, `Þ`, `Æ`)
- **name** — ім’я гліфа без слеша (`elcyr.alt`)

Правила, зліва направо:

1. Пробіл, таб, перенос рядка — роздільник, пропускається.
2. `/` починає ім’я. Ім’я триває до наступного `/`, пробільного символу або кінця рядка. Порожнє ім’я (`//` або зайвий `/` в кінці) ігнорується.
3. Будь-який інший символ — окремий character-токен.

Порядок зберігається. Дублікати не прибираються.

Приклади:

- `g/elcyr.alt` → `g`, `elcyr.alt`
- `/Zhecyr.alt/zhecyr.alt` → `Zhecyr.alt`, `zhecyr.alt`
- `  н о\nг  ` → `н`, `о`, `г`

## Класифікація

Одне поле «Що кернимо». Кожен токен потрапляє в групу за словником `glyph-dictionary.json` (ім’я FontLab і символ) та суфіксами:

- ім’я з `.sc` → **Капітель** (`A.sc`), словник не потрібен
- цифри зі словника / `0`–`9`:
  - без суфікса або `.pnum` → кандидати в **Новостильні** (`1p`)
  - `.onum` → кандидати в **Старостильні** (`1o`)
  - `.pnum.onum` або `.onum.pnum` → пропорційні старостильні
- якщо в наборі є і прості цифри, і `.pnum` — у генерацію лише `.pnum`
- якщо є подвійний суфікс — у старостильні лише він, голий `.onum` відкидається
- решта зі словника: велика (`A`), мала (`a`), пунктуація (`-`), неалфавітні (`@`)

Невідомий токен (немає в словнику і не пояснюється `.sc`) у генерацію не йде; у полі вводу його підсвічують червоним.

## Пари

Для кожного рецепта плану, у якого **обидві** групи присутні у класифікованому наборі:

- ліві гліфи = група Left, праві = група Right
- **Прості** (`A/a`, `A/A.sc`): `[A, B]`
- **Дзеркальні** (решта рецептів): `[A, B, A]`

Порожній набір → порожній рядок. Пари одного лівого гліфа — окремі рядки, між лівими гліфами один порожній рядок (`\n\n`). Між рецептами (групами) — два порожні рядки (`\n\n\n`). Після останнього блоку зайвого переносу немає.

Низькорівневий декарт `left × right` з фіксованим режимом лишається для тестів форматування.

## Формати

Токени збираються в рядок так:

**FontLab.** Усі токени з’єднані слешем. Символ як є, ім’я без додаткового префікса. `н` + `elcyr.alt` + `н` → `н/elcyr.alt/н`.

**Glyphs.** `/` починає ім’я гліфа, звичайні літери пишуться як Unicode:

- character → сам символ
- name → `/` + ім’я
- якщо попередній токен був name, а поточний — character, перед символом ставиться пробіл, щоб ім’я не «з’їло» наступну літеру

Приклади Glyphs: `нон`, `н/elcyr.alt н`, `/Zhecyr.alt/zhecyr.alt`.
